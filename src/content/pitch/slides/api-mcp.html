Tonbab (ต้นแบบ) · ทุกแพ็กเกจได้ API (Free อ่านอย่างเดียว)

Tonbab มีทะเบียนเครื่องมือชุดเดียวที่เปิดให้ใช้สองทาง ทางซ้ายคือ MCP สำหรับผู้ช่วย AI ที่ลูกค้าใช้อยู่แล้ว เช่น Claude, Claude Code, ChatGPT หรือ Gemini CLI ผู้ช่วยทำงานด้วยบัญชีของลูกค้าเอง จึงไม่ใช้เครดิต Tonbab AI แต่นับตามโควตา API ของแพ็กเกจ ผู้ใช้เชื่อมต่อด้วย OAuth กับบริษัทของตัวเอง สิทธิ์ที่ได้คือสิ่งที่ยินยอมและบทบาทอนุญาต ณ ตอนนั้น ทางขวาคือ REST API ด้วย API key ของบริษัท สำหรับ Zapier, Make หรือระบบภายใน พร้อม Webhooks แจ้งเหตุการณ์ การเขียนผ่าน API สร้างได้เฉพาะเอกสารร่างให้คนตรวจก่อน ทุกคำขอถูกบันทึกและจำกัดอัตรา ทุกแพ็กเกจได้ API แพ็กเกจฟรีเป็นแบบอ่านอย่างเดียวพร้อมโควตาจำกัด (ชื่อ Claude ChatGPT Gemini Zapier Make เป็นตัวอย่างเครื่องมือที่เชื่อมได้ ไม่ใช่พาร์ทเนอร์อย่างเป็นทางการ)
