Tonbab (ต้นแบบ) · ทุกแพ็กเกจได้ API (Free อ่านอย่างเดียว)

Tonbab มีทะเบียนเครื่องมือชุดเดียว 107 เครื่องมือ (อ่านข้อมูล 70 ตัว สร้างร่างหรือคำขอ 21 ตัว และย้ายประวัติบัญชีจากระบบเดิม 16 ตัว) ที่เปิดให้ใช้สองทาง ทางซ้ายคือ MCP สำหรับผู้ช่วย AI ที่ลูกค้าใช้อยู่แล้ว เช่น Claude, Claude Code, ChatGPT หรือ Gemini CLI ผู้ช่วยทำงานด้วยบัญชีของลูกค้าเอง จึงไม่ใช้เครดิต Tonbab AI แต่นับตามโควตา API ของแพ็กเกจ ครอบคลุมบัญชี (สรุปยอดขาย ลูกหนี้และเจ้าหนี้ตามอายุ กำไรขาดทุน งบทดลอง ใบแจ้งหนี้ บิลซื้อ รับจ่ายเงิน) สินค้าและสต็อก จัดซื้อ งานขาย CRM บุคลากร (วันลา ใบเบิก) การผลิต งานบริการ และ Docs ตัวอย่างคำถาม: สรุปยอดขายเดือนนี้ตามลูกค้า ลูกค้าคนไหนค้างจ่ายเกิน 30 วัน มีอะไรรอฉันอนุมัติบ้าง ใบลาของฉันเหลือกี่วัน ส่งคำขอลาพรุ่งนี้ให้หน่อย สร้างลีดใหม่และย้ายดีลไปขั้นถัดไป AI เห็นเท่าที่คุณมีสิทธิ์: ผู้ใช้เชื่อมต่อด้วย OAuth ได้สิทธิ์เท่าที่ยินยอมและบทบาทอนุญาต ตรวจใหม่ทุกครั้งที่เรียก คนที่มองไม่เห็นต้นทุน ผู้ช่วยก็ไม่เห็น ไม่มีเงินเดือน เลขบัตรประชาชน หรือค่าคอม หลายบริษัท: ถ้าอยู่หลายบริษัท ตอนเชื่อมต่อติ๊กเลือกบริษัทที่ให้ใช้ได้ ทุกเครื่องมือระบุบริษัทได้ และตรวจสิทธิ์ตามบทบาทในบริษัทนั้น แอดมินบริษัทหนึ่งไม่ได้เป็นแอดมินอีกบริษัท ถามสรุปรวมทุกบริษัทได้ คำตอบแยกทีละบริษัท ไม่รวมยอดข้ามบริษัท ทางขวาคือ REST API ด้วย API key ของบริษัท สำหรับ Zapier, Make หรือระบบภายใน key ทำงานในนามคนที่สร้างและใช้ได้บริษัทเดียว พร้อม Webhooks แจ้งเหตุการณ์ การเขียนทุกทางสร้างได้เฉพาะเอกสารร่างหรือคำขอให้คนอนุมัติ (เช่น ใบขอซื้อ ใบเบิก คำขอลา ลีด บันทึกงาน ร่างใบเสนอราคา ร่างใบส่งของ ร่างใบปรับยอดและใบโอนย้ายสต็อก) และเพิ่มหรือแก้ไขสินค้า รูปสินค้า และคลังได้ ไม่มีอะไรลงบัญชี อนุมัติ จ่ายเงิน หรือลบแทนคน ถ้าผู้ช่วยส่งคำขอซ้ำ ระบบบันทึกครั้งเดียว ทุกคำขอถูกบันทึกและจำกัดอัตรา ทุกแพ็กเกจได้ API แพ็กเกจฟรีอ่านอย่างเดียวพร้อมโควตาจำกัด (ชื่อ Claude ChatGPT Gemini Zapier Make เป็นตัวอย่างเครื่องมือที่เชื่อมได้ ไม่ใช่พาร์ทเนอร์อย่างเป็นทางการ)
