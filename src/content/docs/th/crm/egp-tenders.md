เมนู **งานประมูลภาครัฐ** ดึงประกาศจัดซื้อจัดจ้างจากระบบ e-GP ของกรมบัญชีกลางมาให้อัตโนมัติ ตามคำค้นและหน่วยงานที่คุณติดตาม เซลส์คัดประกาศที่น่าสนใจเข้าไปป์ไลน์ได้ด้วยคลิกเดียว ฟีเจอร์นี้มีในทุกแพ็กเกจ รวมถึง Free

## ประกาศเข้ามาอย่างไร

- ระบบดึงประกาศจากหน่วยงานที่คุณติดตาม วันละ 2 รอบ เวลา 07:35 และ 20:35 น.
- เมื่อมีประกาศใหม่ที่ตรงกับคำค้น ผู้ใช้จะได้รับการแจ้งเตือนในระบบ
- กด **ดึงข้อมูลตอนนี้** เพื่อดึงทันที แต่ระบบ e-GP เปิดให้ดึงข้อมูลเฉพาะช่วงประมาณ 17:00–09:30 น. นอกช่วงนี้จะไม่ได้ข้อมูลใหม่

## ตั้งคำค้นและหน่วยงานที่ติดตาม

ไปที่ **งานประมูลภาครัฐ** › **คำค้นและหน่วยงานที่ติดตาม**

1. ใส่คำค้นที่จะจับคู่กับชื่อโครงการ ระบบจับคู่แบบมีคำนี้อยู่ในชื่อ คำที่สั้นเกินไปจะเจอประกาศไม่เกี่ยวข้องเยอะ ควรใช้คำไทยทั่วไปมากกว่าชื่อยี่ห้อ
2. ใส่ **คำยกเว้น** สำหรับคำที่ไม่ต้องการ
3. กด **ค้นหาผู้ซื้อจากคำค้นของฉัน** ระบบจะจัดอันดับหน่วยงานที่เคยซื้อสินค้าในกลุ่มนี้
4. กด **ติดตาม** ทีละหน่วยงาน หรือ **ติดตามที่เลือก** หรือค้นหาจากรายชื่อหน่วยงานใน e-GP
5. เปิดการส่งอีเมลสรุปเมื่อมีประกาศใหม่ที่ตรงคำค้น ถ้าต้องการ

## คัดประกาศ

หน้างานประมูลมี 4 แท็บ

| แท็บ | ความหมาย |
|---|---|
| ใหม่ | ประกาศที่ยังไม่ได้คัด |
| อยู่ในไปป์ไลน์ | ประกาศที่เพิ่มเป็นดีลแล้ว |
| ข้ามแล้ว | ประกาศที่ตัดสินใจไม่เข้าร่วม |
| สัญญาที่ผ่านมา | ผลการจัดซื้อที่ประกาศผู้ชนะแล้ว ใช้ดูข้อมูลตลาด ไม่ใช่งานที่เปิดรับ |

สำหรับแต่ละประกาศ

- **เพิ่มลงไปป์ไลน์** สร้างดีลในไปป์ไลน์งานประมูล (คีย์ลัด A)
- **ข้าม** พร้อมเหตุผล เช่น ไม่ใช่สินค้าของเรา งบน้อยเกินไป ไกลเกินไป เวลาไม่พอ หรือมีเจ้าเดิมผูกขาด (คีย์ลัด X)
- **เปิดประกาศใน e-GP** เพื่อดูเอกสารต้นฉบับ

## หลังเพิ่มเป็นดีล

ดีลจากงานประมูลทำงานเหมือนดีลทั่วไป มีที่มาเป็น **งานประมูล** เลื่อนขั้น ใส่รายการเสนอราคา และติดตามได้ใน [ดีล](/th/docs/crm/accounts-contacts-deals)

## ถ้าไม่มีประกาศเข้ามา

- ตรวจว่าได้ติดตามหน่วยงานอย่างน้อยหนึ่งแห่งแล้ว
- ลองใช้คำค้นที่กว้างขึ้น
- ถ้าเห็นข้อความว่ายังไม่ได้ตั้งค่า API ให้ติดต่อทีมงาน Tonbab
