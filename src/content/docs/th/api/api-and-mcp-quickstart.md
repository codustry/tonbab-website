Tonbab เชื่อมต่อได้สองแบบ แบบแรกคือ **ตัวเชื่อมต่อ AI (MCP)** ให้ผู้ช่วย AI อย่าง Claude หรือ ChatGPT อ่านข้อมูลในบริษัทของคุณ และเตรียมฉบับร่างหรือคำขอให้คนอนุมัติ แบบที่สองคือ **REST API** สำหรับระบบหรือสคริปต์ของคุณเอง ทุกแพ็กเกจใช้ได้ โดยแพ็กเกจ Free อ่านได้อย่างเดียว

เอกสาร API ฉบับเต็มอยู่ที่ [api.tonbab.com/docs](https://api.tonbab.com/docs)

## หน้าตั้งค่า

ไปที่ **ตั้งค่า** › **API และการเชื่อมต่อ** มีแท็บ **ภาพรวม**, **คีย์ API**, **แอปที่เชื่อมต่อ**, **Webhooks** และ **บันทึกการเรียกใช้** เฉพาะผู้ดูแลเท่านั้นที่แก้ไขการตั้งค่า API ได้

ในส่วน **การตั้งค่าบริษัท** มีสวิตช์ **อนุญาตการเข้าถึง API** และ **อนุญาตการเชื่อมต่อ AI (MCP)** ถ้าปิด คีย์หรือการเชื่อมต่อทั้งหมดของบริษัทจะหยุดทำงานทันที

## เชื่อมจากรายการตัวเชื่อมของ Claude (Connectors Directory)

Tonbab กำลังเข้าไปอยู่ในรายการตัวเชื่อมของ Claude เมื่อขึ้นรายการแล้ว ค้นหา **Tonbab** ใน Claude ได้เลยโดยไม่ต้องวาง URL ระหว่างนี้ให้เพิ่มเป็นตัวเชื่อมแบบกำหนดเอง (หัวข้อถัดไป) ซึ่งใช้งานได้เหมือนกัน

1. ใน Claude ไปที่ **Settings** › **Connectors** แล้วค้นหา **Tonbab** (หรือกด **Add custom connector** แล้ววาง URL `https://api.tonbab.com/mcp`)
2. กด **Connect**
3. ลงชื่อเข้าใช้ Tonbab
4. เลือกบริษัทหลัก ติ๊กบริษัทอื่นที่ให้ Claude ใช้ได้ (ถ้ามี) เลือกว่าให้อ่านข้อมูลส่วนไหนและให้สร้างฉบับร่างได้หรือไม่ แล้วกดอนุญาต
5. เสร็จแล้ว ลองถาม Claude เช่น "ลูกค้าคนไหนค้างจ่ายเกิน 30 วัน"

ถ้าใช้ Claude แบบ Team หรือ Enterprise เจ้าของบัญชีองค์กรต้องเพิ่ม Tonbab ให้ทั้งองค์กรก่อน แล้วสมาชิกแต่ละคนกด **Connect** และลงชื่อเข้าใช้ด้วยบัญชี Tonbab ของตัวเอง

Claude ทำงานในนามคุณ ตามบทบาทและสิทธิ์ของคุณใน Tonbab และเฉพาะบริษัทที่คุณติ๊กไว้ สิ่งที่สร้างเป็นฉบับร่างหรือคำขอให้คนยืนยันหรืออนุมัติใน Tonbab เสมอ ยกเลิกการเชื่อมต่อได้ทุกเมื่อที่แท็บ **แอปที่เชื่อมต่อ** ดูขั้นตอนและตัวอย่างคำถามแต่ละโมดูลได้ที่ [เชื่อมต่อ Tonbab กับ Claude](/th/connect/claude)

## เชื่อม Claude หรือ ChatGPT ผ่าน MCP

URL ของตัวเชื่อมต่อคือ `https://api.tonbab.com/mcp`

1. ใน Claude ไปที่ Settings › Connectors › Add custom connector หรือใน ChatGPT เปิด developer mode (Settings › Apps & Connectors › Advanced) แล้วสร้าง connector แบบ OAuth
2. วาง URL ด้านบนแล้วกดเชื่อมต่อ
3. ลงชื่อเข้าใช้ Tonbab เลือก **บริษัท** (บริษัทหลัก) ในส่วน **อนุญาตบริษัทเหล่านี้ด้วย** ติ๊กบริษัทอื่นที่ให้ใช้ได้ ถ้าไม่ติ๊กเลยจะเชื่อมบริษัทเดียว เลือกสิทธิ์ แล้วกดอนุญาต

แต่ละการเชื่อมต่อทำงานในนามของคนที่เชื่อมต่อ และอยู่ในขอบเขตสิทธิ์ของบทบาทนั้น ดูและยกเลิกการเชื่อมต่อได้ที่แท็บ **แอปที่เชื่อมต่อ**

### ผู้ช่วยเข้าถึงอะไรได้บ้าง

มี 93 เครื่องมือ อ่านข้อมูล 66 ตัว สร้างฉบับร่าง คำขอ หรืออัปเดต CRM 11 ตัว และย้ายข้อมูลย้อนหลังจากระบบเดิม 16 ตัว แต่ละหมวดจะใช้ได้เมื่อเปิดโมดูลนั้นและบทบาทของคุณเปิดดูได้

- **บัญชี**: สรุปยอดขาย ลูกหนี้และเจ้าหนี้ค้างชำระตามอายุ กำไรขาดทุน งบทดลอง ใบแจ้งหนี้ บิลซื้อ ใบเสนอราคา รับ-จ่ายเงิน ผังบัญชี บัญชีธนาคาร (แสดงเลข 4 ตัวท้าย) สินทรัพย์ถาวร รหัส VAT และอัตราภาษีหัก ณ ที่จ่ายที่ใช้บ่อย
- **สินค้าและสต็อก**: สินค้า หน่วยนับ ยอดคงเหลือ คลัง ความเคลื่อนไหว ล็อต ซีเรียล มูลค่าสต็อก (เฉพาะคนที่เห็นต้นทุน)
- **จัดซื้อ**: ใบขอซื้อ ใบสั่งซื้อ ใบรับสินค้า
- **งานขาย**: ออเดอร์และใบส่งของ
- **ลูกค้า ผู้ขาย และ CRM**: บริษัทคู่ค้า ผู้ติดต่อ ลีด ดีล ไปป์ไลน์และขั้นตอนการขาย กิจกรรม และรายงานไปป์ไลน์ ทั้งมูลค่าดีลที่เปิดอยู่ ยอดคาดการณ์ อัตราปิดการขาย และเหตุผลที่แพ้ดีล (ดีลและลีดเห็นตามสายงานเหมือนในแอป)
- **บุคลากร**: รายชื่อพนักงาน (ข้อมูลติดต่อเท่านั้น) วันลาคงเหลือของฉัน ใบลา ใบเบิกค่าใช้จ่าย
- **การผลิตและงานบริการ**: ใบสั่งผลิต Job Control พร้อมงบและต้นทุน (ต้นทุนเฉพาะคนที่เห็นต้นทุน) สูตรการผลิต (BOM) งานซ่อมบริการ และตารางงานช่าง
- **Docs**: ค้นหน้าเอกสาร อ่านหน้า และแถวในฐานข้อมูล
- **งานรออนุมัติ**: รายการที่รอคุณอนุมัติ (ใบขอซื้อ ใบเบิกค่าใช้จ่าย ใบลา โอที และอื่น ๆ) รายการที่รอนานที่สุดรอมากี่วัน พร้อมลิงก์ไปตัดสินใจใน Tonbab
- **ข้อมูลอ้างอิง**: สมาชิกในบริษัท (ให้ผู้ช่วยเรียกชื่อคนได้ถูก) ไปป์ไลน์และขั้นตอนการขาย หน่วยนับ อัตรา VAT และภาษีหัก ณ ที่จ่าย
- **ย้ายข้อมูลจากระบบเดิม**: ผู้ติดต่อ สินค้า ยอดยกมา บัญชีแยกประเภท เอกสาร รับ-จ่ายเงิน ภาษีหัก ณ ที่จ่าย สินทรัพย์ถาวร และประวัติการซื้อ ทำภายในงานย้ายข้อมูลที่คนเปิดไว้ มีการทดลองนำเข้าและกระทบยอดก่อนมีคนอนุมัติ
- **สร้างอะไรได้บ้าง**: ฉบับร่างใบขอซื้อ ใบตรวจนับสต็อก และใบเบิกค่าใช้จ่าย ใบลาของตัวเอง (ผู้อนุมัติเป็นคนตัดสิน) ลูกค้า/ผู้ขาย ลีด ดีล กิจกรรม และอัปเดตงานใน CRM รวมถึงย้ายขั้นตอนหรือปิดดีลที่คุณดูแลเป็นได้หรือแพ้

**ส่งซ้ำได้อย่างปลอดภัย** ทุกเครื่องมือที่เขียนข้อมูลรับ `client_request_id` ได้ ถ้าการเชื่อมต่อหลุดแล้วผู้ช่วยส่งคำขอเดิมซ้ำภายใน 24 ชั่วโมง Tonbab จะคืนผลครั้งแรกให้ ไม่สร้างรายการซ้ำ

เงินเดือน ข้อมูลการจ่ายเงินเดือน เลขบัตรประชาชน และค่าคอมมิชชันไม่เปิดให้ผู้ช่วยเห็นเลย

### หลายบริษัท

ถ้าคุณอยู่หลายบริษัท การเชื่อมต่อครั้งเดียวใช้ได้กับบริษัทที่คุณติ๊กตอนลงชื่อเข้าใช้เท่านั้น ไม่มีบริษัทอื่น

- ในแต่ละบริษัท ผู้ช่วยเห็นได้เท่าที่ **บทบาทของคุณในบริษัทนั้น** เห็น เป็นแอดมินในบริษัทหนึ่งไม่ได้สิทธิ์อะไรเพิ่มในอีกบริษัท
- ทุกครั้งที่เรียกจะตรวจสิทธิ์ใหม่ในบริษัทนั้น
- ถามว่า "เห็นบริษัทไหนบ้าง" ผู้ช่วยจะเรียก `list_my_companies` ให้
- การสรุปยอดขาย ลูกหนี้ เจ้าหนี้ กำไรขาดทุน และมูลค่าสต็อก ถามรวมทุกบริษัทได้ คำตอบจะแยกทีละบริษัท ไม่รวมยอดข้ามบริษัท

คีย์ API ใช้ได้กับบริษัทเดียวเสมอ

การเชื่อมผู้ช่วย AI ไม่ใช้เครดิต AI ของคุณ ผู้ช่วยทำงานด้วยบัญชี Claude, ChatGPT หรือ Gemini ของคุณเอง และการดึงข้อมูลแต่ละครั้งนับตามขีดจำกัด API ด้านล่าง

### หมายเหตุสำหรับผู้ช่วยแต่ละตัว

- **Claude** (claude.ai แอปเดสก์ท็อป และมือถือ): แพ็กเกจ Team หรือ Enterprise ของ Claude ให้เจ้าของบัญชีองค์กรเพิ่มตัวเชื่อมแบบกำหนดเองก่อน แล้วสมาชิกกด **Connect** แพ็กเกจฟรีของ Claude เพิ่มตัวเชื่อมแบบกำหนดเองได้ 1 ตัว
- **ChatGPT**: ตัวเชื่อม MCP แบบกำหนดเองต้องเปิด Developer mode ซึ่งผู้ดูแล workspace เป็นผู้เปิด ตอนนี้ OpenAI เปิดให้ workspace แบบ Business, Enterprise และ Edu ChatGPT เข้าสู่ระบบด้วย OAuth เท่านั้น ใช้คีย์ API ไม่ได้
- **Gemini CLI**: เพิ่ม Tonbab ในไฟล์ `~/.gemini/settings.json` แล้วพิมพ์ `/mcp auth tonbab` ใน `gemini` เพื่อลงชื่อเข้าใช้

  ```json
  { "mcpServers": { "tonbab": { "httpUrl": "https://api.tonbab.com/mcp" } } }
  ```

- **Claude Code**: รัน `claude mcp add --transport http tonbab https://api.tonbab.com/mcp` แล้วพิมพ์ `/mcp` เพื่อลงชื่อเข้าใช้

แอปอื่นที่เพิ่ม MCP server ด้วย URL และลงชื่อเข้าใช้แบบ OAuth ได้ ก็เชื่อมต่อแบบเดียวกัน ถ้าเป็นสคริปต์ที่ทำงานเอง ให้ส่งคีย์ API ของบริษัทในส่วนหัว `Authorization: Bearer` แทน

## สร้างคีย์ REST API

1. ไปที่แท็บ **คีย์ API** แล้วกด **สร้างคีย์ API**
2. ตั้ง **ชื่อ** เช่น "ซิงก์ Shopify"
3. เลือก **โหมด**
   - **ใช้งานจริง**
   - **ทดสอบ** อ่านข้อมูลจริงได้ แต่การเขียนจะตรวจสอบเท่านั้น ไม่บันทึกจริง เหมาะสำหรับพัฒนาระบบ
4. เลือกสิทธิ์ **อ่าน** และ/หรือ **สร้างร่าง** ให้คีย์ได้เฉพาะสิทธิ์ที่คุณมีเท่านั้น คีย์ทำงานในนามคุณ ถ้าสิทธิ์ของคุณเปลี่ยนภายหลัง สิทธิ์ของคีย์ก็เปลี่ยนตาม และคีย์จะหยุดทำงานถ้าคุณออกจากบริษัท
5. ตั้ง **หมดอายุ** และ **IP ที่อนุญาต (ไม่บังคับ)** สูงสุด 20 รายการ
6. กด **สร้างคีย์** แล้วคัดลอกเก็บทันที คีย์จะไม่แสดงอีก

เรียก API ที่ `https://api.tonbab.com/v1` โดยส่งคีย์ในส่วนหัวแบบ Bearer token

```
Authorization: Bearer <คีย์ของคุณ>
```

## เขียนได้แค่ฉบับร่างและคำขอ

การสร้างข้อมูลผ่าน API หรือ AI จะได้ **ฉบับร่าง** **คำขอ** ที่รออนุมัติตามขั้นตอนปกติ หรือการอัปเดตงาน CRM ของคุณเอง (ลีด อัปเดตงาน ขั้นตอนของดีล) คนยังต้องเป็นผู้ส่ง อนุมัติ ลงบัญชี และจ่ายเงินใน Tonbab เอง ทำให้ AI หรือระบบภายนอกไม่สามารถอนุมัติ ลงบัญชี หรือจ่ายเงินแทนคนได้

ส่งซ้ำได้อย่างปลอดภัย: การเรียก REST ใส่ส่วนหัว `Idempotency-Key` และการเขียนผ่านตัวเชื่อมต่อ AI ใส่ `client_request_id` คำขอเดียวกันที่ส่งสองครั้งจะบันทึกเพียงครั้งเดียว

## Webhooks

1. ไปที่แท็บ **Webhooks** แล้วกด **เพิ่ม Webhook**
2. ใส่ **URL ปลายทาง (https)** ต้องเป็น URL สาธารณะ
3. เลือกเหตุการณ์ หรือ **ทุกเหตุการณ์**
4. กด **ส่งทดสอบ** เพื่อตรวจว่ารับได้

ทุกครั้งที่ส่งจะลงลายมือชื่อด้วยส่วนหัว `Tonbab-Signature` (HMAC-SHA256) ใช้รหัสลงลายมือชื่อของ Webhook นั้นตรวจสอบ ถ้าส่งไม่สำเร็จ ระบบจะลองใหม่ประมาณ 3 วัน ดู **การส่งล่าสุด** และกด **ส่งอีกครั้ง** ได้

## ตรวจการใช้งาน

แท็บ **บันทึกการเรียกใช้** แสดงการเรียก API และการเชื่อมต่อ 200 รายการล่าสุด พร้อมสถานะ เวลา และรหัสคำขอ ใช้ตรวจปัญหาเวลาเชื่อมระบบ

## ความปลอดภัย

- ยกเลิกคีย์ที่ไม่ใช้ด้วย **ยกเลิก** ระบบที่ใช้คีย์นั้นจะหยุดทำงานทันที
- จำกัด IP สำหรับคีย์ที่ใช้จากเซิร์ฟเวอร์
- ใช้คีย์โหมด **ทดสอบ** ระหว่างพัฒนา
