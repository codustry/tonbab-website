Tonbab ดึงออเดอร์จาก Shopee และ Lazada เข้ามารวมกับออเดอร์หน้าร้านได้อัตโนมัติ ออเดอร์ที่ชำระแล้วจะจองสต็อกในคลังที่คุณเลือก และเมื่อกดจัดส่งใน Tonbab ระบบจะแจ้งมาร์เก็ตเพลสให้ด้วย

## สถานะของแต่ละช่องทาง

| ช่องทาง | สถานะ |
|---|---|
| Shopee ซิงก์ออเดอร์และแจ้งจัดส่ง | ใช้งานได้ |
| Lazada ซิงก์ออเดอร์และแจ้งจัดส่ง | ใช้งานได้ |
| ส่งยอดสต็อกกลับไปที่ Shopee / Lazada | อยู่ระหว่างพัฒนา |
| TikTok Shop | เร็ว ๆ นี้ |
| LINE Shopping | เร็ว ๆ นี้ |
| แชท LINE OA, Messenger, Instagram | ใช้งานได้ ดู [กล่องแชท](/th/docs/commerce/chat-inbox) |
| แชท Shopee / Lazada | ยังไม่รองรับ |

ระหว่างที่การส่งยอดสต็อกกลับยังไม่เปิด ให้ปรับจำนวนสต็อกในหลังร้านของ Shopee และ Lazada เองตามเดิม

## ช่องทางขายอยู่ในแพ็กเกจไหน

ช่องทางขายทั้งหมดรวมอยู่ในแพ็กเกจ Enterprise ส่วนแพ็กเกจ Business ซื้อเพิ่มได้ในราคา 3,600 บาทต่อปี (ครอบคลุมทุกช่องทาง) ดู [แพ็กเกจและค่าบริการ](/th/docs/getting-started/plans-and-billing)

## เชื่อมร้าน Shopee หรือ Lazada

1. ไปที่ **คอมเมิร์ซ** › **ตั้งค่าคอมเมิร์ซ** › **ช่องทางการขาย** แล้วเลือก **มาร์เก็ตเพลส**
2. กด **เพิ่มร้าน**
3. เลือกแพลตฟอร์ม ตั้งชื่อร้าน และเลือก **จัดส่งจากคลัง** (คลังที่จะจองและตัดสต็อก)
4. ติ๊ก **Enable this shop** แล้วกด **บันทึกร้าน**
5. อนุญาตการเข้าถึงร้านบนหน้าของ Shopee หรือ Lazada (ล็อกอินด้วยบัญชีผู้ขาย) เมื่อเสร็จ สถานะจะเปลี่ยนเป็น **เชื่อมต่อแล้ว**

ส่วน **Advanced — use my own developer app** ไม่ต้องเปิด ใช้เฉพาะกรณีที่มีแอปนักพัฒนาของตัวเอง

## การซิงก์ออเดอร์

ระบบดึงออเดอร์ใหม่ตามรอบเวลาให้อัตโนมัติ ถ้าต้องการดึงทันที กด **ซิงก์เดี๋ยวนี้**

สถานะจากมาร์เก็ตเพลสแปลงเป็นสถานะใน Tonbab ดังนี้

| สถานะในมาร์เก็ตเพลส | สถานะใน Tonbab |
|---|---|
| ยังไม่ชำระ / รอดำเนินการ | รอดำเนินการ |
| พร้อมส่ง / ส่งแล้ว / ถึงแล้ว / สำเร็จ | ชำระแล้ว (เข้าขั้นจัดส่งและจองสต็อก) |
| ยกเลิก / คืนสินค้า / คืนเงิน | ยกเลิก |

## จัดส่งและแจ้งกลับ

ออเดอร์จากมาร์เก็ตเพลสจัดส่งผ่านหน้า [ออเดอร์](/th/docs/commerce/orders-and-customers) เหมือนออเดอร์อื่น เมื่อกด **ทำเครื่องหมายว่าจัดส่งแล้ว**

- Tonbab ตัดสต็อกจากคลังที่ผูกไว้
- แจ้ง Shopee หรือ Lazada ว่าจัดส่งแล้ว (Lazada จะออกเลขพัสดุให้)
- ถ้าสำเร็จจะขึ้น **แจ้งมาร์เก็ตเพลสแล้ว** ถ้าไม่สำเร็จจะมีข้อความให้ตรวจสอบการเชื่อมต่อ

## ช่องทางอื่น

- **หน้าร้าน** ขายผ่าน [POS](/th/docs/commerce/pos)
