POS ของ Tonbab เป็นแอปขายหน้าร้านที่ทำงานบนแท็บเล็ต มือถือ หรือเครื่อง Sunmi ขายแล้วตัดสต็อกจากคลังของร้านทันที รับชำระได้ทั้งพร้อมเพย์ QR ของร้านเอง บัตรและ QR ผ่าน Beam และบันทึกการรับเงินสด

## ตั้งค่าก่อนขาย

การตั้งค่า POS อยู่ที่ **คอมเมิร์ซ** › **ตั้งค่าคอมเมิร์ซ** › **POS** ซึ่งมีแท็บดังนี้

| แท็บ | ใช้ทำอะไร |
|---|---|
| แคตตาล็อก POS | เลือกสินค้าที่แสดงบนหน้าขาย (**แสดงบน POS** / **ซ่อนจาก POS**) ถ้าไม่เลือกเลย สินค้าที่ขายได้ทุกตัวจะแสดง |
| เมนูร้าน | ตั้งเมนู ราคา โลโก้ พร้อมเพย์ และตัวอักษรนำหน้าคิวแยกตามร้าน (สำหรับหลายแบรนด์) |
| ร้านอาหารและคาเฟ่ | รูปแบบการทาน ค่าบริการ เลขคิว และยกเลิกออเดอร์ค้างชำระอัตโนมัติ |
| ตัวเลือกเมนู | ขนาด ความหวาน ท็อปปิ้ง และสูตร |
| เครื่องพิมพ์ | เครื่องพิมพ์ใบเสร็จและใบสั่งงาน |
| อุปกรณ์คีออส | จับคู่แท็บเล็ตกับร้านและคลัง |
| ผู้ใช้งาน POS | สร้าง PIN พนักงานและผู้อนุมัติคืนเงิน |

ขั้นตอนจับคู่เครื่องและสร้าง PIN อยู่ใน [ติดตั้งแอปและโหมดคีออสก์](/th/docs/getting-started/install-app) พนักงานที่ใช้ PIN ไม่นับเป็นผู้ใช้ตามแพ็กเกจ

## ตั้งค่าการชำระเงิน

ไปที่ **ตั้งค่าคอมเมิร์ซ** › **การชำระเงิน** แล้วเลือก **วิธีชำระเงินที่รับ**

- **พร้อมเพย์ (QR ร้าน)** ไม่มีค่าธรรมเนียม ใส่ **หมายเลขพร้อมเพย์** (เบอร์มือถือ เลข 13 หลัก หรือ e-Wallet) หรือ **อัปโหลดรูป QR** ตั้งได้ว่า **บังคับแนบรูปสลิป** และ **ใครยืนยันได้โดยไม่มีสลิป**
- **ตรวจสลิปอัตโนมัติ** (Starter ขึ้นไป) ระบบไม่รับสลิปที่ยอดน้อยกว่าบิล โอนเข้าพร้อมเพย์อื่น เก่ากว่า 24 ชั่วโมง หรือเคยใช้แล้ว
- **Beam Checkout** รับบัตรเครดิต/เดบิตและพร้อมเพย์ผ่าน Beam ใส่ Merchant ID, Secret API key และ Webhook signing secret แล้วนำ Webhook URL ที่ระบบแสดงไปใส่ใน Beam
- **เงินสด** และ **บันทึกการชำระเอง** สำหรับเงินสดหรือเครื่องรับบัตรแยก

## ขายสินค้า

1. เปิดแอป POS แล้วเข้าด้วย PIN
2. ค้นหาหรือแตะสินค้า รายการจะเข้า **รายการขาย**
3. ใส่ **ส่วนลดรายการ** หรือ **ส่วนลดท้ายบิล** และ **รูปแบบการทาน** ถ้ามี
4. กด **รับชำระ** แล้วเลือกวิธี
   - **พร้อมเพย์ (QR ร้าน)** ให้ลูกค้าสแกน แล้ว **ถ่ายรูปสลิป** หรือ **อัปโหลดสลิป** และกด **ยืนยันได้รับเงินแล้ว**
   - **พร้อมเพย์** หรือ **บัตร** ผ่าน Beam ระบบรอการชำระและยืนยันให้อัตโนมัติ
   - **บันทึกเอง** เลือก **เงินสด** ใส่เงินที่รับเพื่อคำนวณ **เงินทอน** แล้วกด **บันทึกการชำระ**
5. หน้า **ขายสำเร็จ** มี **พิมพ์ใบเสร็จ**, **ส่งใบเสร็จทางอีเมล** และ **ขายรายการใหม่**

## เก็บข้อมูลลูกค้า (ไม่บังคับ)

ในหน้าขายสำเร็จ กด **ค้นหาสมาชิก** แล้ว **ผูก** หรือ **ลูกค้าใหม่** แล้ว **บันทึกและผูก** ข้อมูลจะไปอยู่ใน [ลูกค้า](/th/docs/commerce/orders-and-customers) พร้อมประวัติการซื้อ

## เครื่องพิมพ์ใบเสร็จ

- **เครื่อง Sunmi ที่มีเครื่องพิมพ์ในตัว** กดไอคอนเครื่องพิมพ์ที่หัวจอ › **เครื่องพิมพ์ของเครื่องนี้** › **พิมพ์ที่เครื่องนี้** เลือกกระดาษ 58 หรือ 80 มม. แล้ว **พิมพ์ใบทดสอบ** (ใช้ Sunmi Browser จะพิมพ์ได้ทันทีโดยไม่มีหน้าต่างพิมพ์)
- **เครื่องพิมพ์เครือข่าย** ที่ **เครื่องพิมพ์** › **เพิ่มเครื่องพิมพ์** เลือกหน้าที่ **ใบเสร็จลูกค้า** หรือ **ใบสั่งงาน** แล้วเลือกวิธีเชื่อมต่อ **ในเครือข่ายร้าน** (ใส่ IP) หรือ **ดึงงานจาก Tonbab** (วาง URL ในเครื่องพิมพ์) แล้วกด **พิมพ์ทดสอบ**

ถ้ายังไม่ได้ตั้งเครื่องพิมพ์ POS จะใช้หน้าต่างพิมพ์ของเบราว์เซอร์

## คืนเงิน

1. ไปที่แท็บ **ออเดอร์** ในแอป POS เปิดออเดอร์ แล้วกด **คืนเงิน**
2. เลือกรายการและจำนวน (หรือ **เลือกทั้งหมด**) และเลือกเหตุผล
3. เลือก **คืนเงินเป็น**: ช่องทางเดิม เงินสด โอนเงิน หรือเครดิตร้าน
4. เลือกว่าจะ **คืนสินค้าเข้าสต็อก** หรือไม่
5. ผู้จัดการกรอก **PIN ผู้จัดการ** แล้วกด **ยืนยันคืนเงิน**

ออเดอร์ที่ยังไม่ชำระ ยกเลิกได้ด้วย **ยกเลิกออเดอร์**

## ปิดยอดวันนี้

**ปิดยอดวันนี้** แสดงรายงานสรุปของวัน ได้แก่ **ยอดสุทธิ** ยอดแยก **ตามการชำระเงิน** และการคืนเงิน ส่งออกด้วย **ส่งออก CSV** หรือเปิด **รายงานฉบับเต็ม** หน้านี้เป็นรายงาน ยังไม่มีขั้นตอนนับเงินสดในลิ้นชักเทียบยอด
