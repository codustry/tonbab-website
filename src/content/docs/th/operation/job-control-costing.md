จ๊อบคอนโทรล (Job Control) คือแฟ้มของงานหนึ่งงาน เช่น โครงการลูกค้า งานภายใน หรือการผลิตเข้าสต็อก ทุกเอกสารที่ผูกกับงาน ทั้งใบขอซื้อ ใบสั่งซื้อ ใบรับสินค้า ใบสั่งผลิต ใบส่งของ และค่าใช้จ่าย จะรวมต้นทุนมาที่นี่ ให้เห็นทันทีว่างานใช้งบไปเท่าไรเทียบกับที่อนุมัติ

## สร้างจ๊อบ

1. ไปที่ **งานและการผลิต** › **จ๊อบคอนโทรล** แล้วกด **สร้างใบควบคุมงาน**
2. เลือก **ประเภทงาน**: โครงการลูกค้า, งานภายใน, ผลิตเข้าสต็อก หรือบำรุงรักษา
3. ใส่ **งบประมาณที่อนุมัติ**
4. กด **สร้างงาน**

จากดีลใน CRM ก็สร้างจ๊อบได้ด้วยปุ่ม **สร้าง Job Control**

## สถานะของงาน

แบบร่าง › **เปิดใช้งาน** › ดำเนินการ › (**พักไว้** / **ดำเนินการต่อ**) › **เสร็จสิ้น** › **ปิด**

การปิดงานต้องใช้สิทธิ์ปิดจ๊อบ และยกเลิกงานได้ด้วยปุ่มยกเลิก

## ต้นทุนมาจากไหน

| ประเภท | ที่มา |
|---|---|
| **ผูกพัน** | ใบสั่งซื้อที่ออกแล้วแต่ยังไม่ได้รับของ |
| **ใช้จริง** วัตถุดิบ | ของที่รับเข้าตาม PR ประเภทจ๊อบ (ต้นทุนถึงมือ) และของที่เบิกจากสต็อกผ่านใบสั่งผลิตหรือใบส่งของ (ต้นทุนเฉลี่ย) |
| **ใช้จริง** ค่าบริการ | รายการบริการใน PO ที่รับแล้ว |
| **ใช้จริง** ค่าใช้จ่าย | เบิกค่าใช้จ่ายที่ผูกกับงาน |
| **ใช้จริง** งานบริการ | ค่าแรงและค่าเดินทางจากงานบริการ |

ราคาประเมินในใบขอซื้อเป็นข้อมูลประกอบเท่านั้น ไม่นับเป็นการใช้งบ ระบบหักลบรายการที่ซ้ำกันให้ จึงไม่นับต้นทุนเดียวกันสองครั้ง

การคิดต้นทุนจากการเบิกสต็อกต้องเปิดการติดตามต้นทุนไว้ที่ **ตั้งค่า** › **สต็อกและต้นทุน**

## อ่านหน้าจ๊อบ

ด้านบนมีแถบงบประมาณแสดง "ใช้ไป + ผูกพัน" เทียบกับงบที่อนุมัติ ถ้าเกินงบ จะแสดงเปอร์เซ็นต์ที่เกิน ส่วนอื่น ๆ แบ่งเป็นแท็บ เริ่มจากภาพรวม

## กำไร/ขาดทุนของงาน

ส่วน **กำไร/ขาดทุนของงาน** เทียบงบกับต้นทุน

ผลต่าง = งบประมาณ − (ผูกพัน + ใช้จริง)

## จ้างผู้รับเหมา

ในส่วน **งานจ้างภายนอก** กด **จ้างผู้รับเหมา** เพื่อสร้างใบขอซื้อบริการฉบับร่างที่ผูกกับงานนี้ แล้วดำเนินการตาม [ใบขอซื้อ](/th/docs/operation/purchase-requests)

## เคล็ดลับ

- ผูก PR ทุกใบที่ซื้อเพื่องานกับจ๊อบตั้งแต่แรก ด้วยประเภทการเบิก **จ๊อบ / โครงการ**
- รายการค่าแรงหรือค่าติดตั้งใน PO ให้ใช้รายการ **บริการ / ค่าแรง** และผูกจ๊อบ ไม่อย่างนั้นต้นทุนจะไม่เข้างาน
- ดูต้นทุนวัตถุดิบตามแผนเทียบกับจริงของการผลิตได้ที่ [ใบสั่งผลิต](/th/docs/operation/work-orders-and-bom)
