ใบขอซื้อ (PR) คือจุดเริ่มของการจัดซื้อใน Tonbab ผู้ขอซื้อสร้างและส่ง PR ฝ่ายจัดซื้อหาผู้ขายและราคา ผู้มีอำนาจอนุมัติ แล้วระบบสร้างใบสั่งซื้อ (PO) แยกตามผู้ขายให้อัตโนมัติ

## สร้างใบขอซื้อ

1. ไปที่ **ปฏิบัติการ** › **จัดซื้อ** › **ใบขอซื้อ** แล้วกด **สร้างใบขอซื้อ**
2. เลือก **ประเภทการเบิก**
   - **จ๊อบ / โครงการ** ต้นทุนจะเข้า [จ๊อบคอนโทรล](/th/docs/operation/job-control-costing)
   - **เติมสต็อก** ซื้อเข้าคลัง
   - **ค่าใช้จ่าย** ซื้อใช้ทั่วไป
3. เพิ่มรายการด้วย **เพิ่มรายการ** หรือ **เพิ่มหลายรายการ** ถ้าเป็นค่าแรงหรืองานจ้าง ให้ติ๊ก **บริการ / ค่าแรง** ถ้าสินค้ามีสูตรการผลิต กด **ขยาย BOM** เพื่อแตกเป็นวัตถุดิบ
4. กด **สร้าง PR (ร่าง)** แล้วกด **ส่ง** เมื่อพร้อม

ในหน้ารายการยังมี **ตรวจสอบสินค้าขาด** (รายการที่ใบสั่งผลิตขาดวัตถุดิบ) และ **รวมความต้องการสั่งซื้อ** เพื่อรวมความต้องการจากหลายแหล่งเป็น PR เดียว

## ขั้นตอนและสถานะ

| สถานะ | ใครทำอะไร | ปุ่ม |
|---|---|---|
| แบบร่าง | ผู้ขอแก้ไขและส่ง | **ส่ง** |
| ส่งขออนุมัติแล้ว | ฝ่ายจัดซื้อรับเรื่อง | **เริ่มตรวจสอบ** |
| อยู่ระหว่างจัดซื้อ | ฝ่ายจัดซื้อใส่ผู้ขายและราคาทุกรายการ | **เสร็จสิ้นการจัดหา** |
| รออนุมัติ | ผู้อนุมัติตัดสินใจ | **อนุมัติ** / **ปฏิเสธ** |
| อนุมัติแล้ว | ฝ่ายจัดซื้อออก PO | **สร้างใบสั่งซื้อ** |
| ปฏิเสธแล้ว | ส่งกลับไปแก้ | **เปิดจัดหาใหม่** / **ย้อนกลับเป็นฉบับร่าง** |

เมื่อสร้าง PO แล้ว สถานะจะเป็น **แปลงบางส่วนแล้ว** หรือ **แปลงทั้งหมดแล้ว** ปุ่ม **สร้างใบสั่งซื้อ** สร้าง PO ฉบับร่างหนึ่งใบต่อผู้ขายหนึ่งราย ถ้ามี PR อื่นที่อนุมัติแล้วและใช้ผู้ขายรายเดียวกัน จะมีปุ่ม **รวมกับอีก {n} ใบขอซื้อ** ให้รวมเป็น PO เดียว

## หน้าอนุมัติ

ผู้อนุมัติดูงานที่รออยู่ทั้งหมดได้ที่ **อนุมัติ** ในแถบข้าง หน้านี้รวม PR ที่ **รออนุมัติ** คำขอย้อนสถานะ PR / PO คำขอย้อนการตัดสต็อกใบส่งของ รวมถึงคำขอลา โอที และค่าใช้จ่ายไว้ในที่เดียว

## อนุมัติอัตโนมัติ (ไม่บังคับ)

บริษัทเปิดให้ PR ที่มูลค่าต่ำกว่าเพดานที่กำหนดอนุมัติเองได้ ค่าเริ่มต้นคือปิด ในโหมดเข้มงวด ทุกรายการต้องมีผู้ขายประจำพร้อมราคาที่ตกลงไว้ (เป็นเงินบาทและยังไม่หมดอายุ) จึงจะอนุมัติอัตโนมัติ

## แก้ไขหลังอนุมัติและการอนุมัติซ้ำ

PR ที่อนุมัติแล้วแต่ยังไม่ได้ออก PO ยังแก้ไขได้ แต่ระบบจะส่งกลับไป **รออนุมัติ** อีกครั้งเมื่อ

- เพิ่ม ลบ หรือเปลี่ยนสินค้าบางรายการ
- ยอดรวมสูงขึ้นเกินเกณฑ์ที่ยอมรับได้ (ค่าเริ่มต้น 10% ปรับได้ต่อบริษัท)

PR จะแสดงข้อความ **คำขอนี้ถูกแก้ไขและต้องอนุมัติใหม่** และผู้ขอจะได้รับแจ้งเตือน ถ้าต้องการเปลี่ยนสินค้าเป็นตัวทดแทน ให้ใช้ช่อง **รายการนี้แทนที่ (การทดแทน)** ในฟอร์มแก้ไข รายการนั้นจะแสดงว่า **แทนที่ #{n} {item}** ให้ผู้อนุมัติเห็นชัด

## ล็อกตามลำดับเอกสาร

เมื่อสร้าง PO จาก PR แล้ว PR จะถูกล็อก ถ้าต้องการแก้ ต้องลบ PO (และใบรับสินค้าที่อยู่บน PO นั้น) ก่อน ผู้ที่ไม่มีสิทธิ์ย้อนสถานะเองจะเห็นปุ่ม **ขอย้อนกลับ** แทน คำขอจะไปที่หน้าอนุมัติ

## ขั้นต่อไป

- เปรียบเทียบใบเสนอราคาจากหลายผู้ขายในแท็บ **เปรียบเทียบราคา**: [การเปรียบเทียบราคา (RFQ)](/th/docs/operation/rfq-price-comparison)
- ออกและพิมพ์ใบสั่งซื้อ: [ใบสั่งซื้อ](/th/docs/operation/purchase-orders)
