ผู้ดูแลระบบเพิ่มผู้ใช้ได้ที่ **ตั้งค่าผู้ใช้งาน** แล้วกำหนด **บทบาท** ให้แต่ละคน บทบาทเป็นชุดสิทธิ์พื้นฐาน และถ้าต้องการให้ใครทำได้มากกว่าบทบาทของตัวเอง ก็เพิ่ม **สิทธิ์เฉพาะบุคคล** ได้ทีละรายการ

## จำนวนผู้ใช้ตามแพ็กเกจ

| แพ็กเกจ | ผู้ใช้ที่รวมอยู่ |
|---|---|
| Free | 1 คน |
| Starter | 5 คน |
| Standard | 10 คน |
| Business | 25 คน |
| Enterprise | ไม่จำกัด (เสนอราคาตามองค์กร) |

หน้า **ผู้ใช้งาน** จะแสดงว่าใช้ไปแล้วกี่คนจากโควตา ถ้าเต็มแล้วจะมีปุ่ม **อัปเกรดแพ็กเกจ** ส่วนพนักงานหน้าร้านที่เข้าระบบด้วย PIN บนเครื่องคีออสก์ (เช่น POS และสถานีแพ็ก) **ไม่นับเป็นผู้ใช้**

## เพิ่มผู้ใช้ใหม่

1. ไปที่ **ตั้งค่าผู้ใช้งาน** แล้วกด **เพิ่มผู้ใช้**
2. กรอก **ชื่อที่แสดง**, **อีเมล**, เบอร์โทร และ **แผนก**
3. เลือก **บทบาท** อย่างน้อยหนึ่งบทบาท
4. กด **เพิ่มผู้ใช้** ระบบจะส่งอีเมลเชิญให้ผู้ใช้ตั้งรหัสผ่านและเข้าสู่ระบบเอง

## บทบาทที่มีให้

| บทบาท | ใช้ทำอะไร |
|---|---|
| ผู้ดูแลระบบ | เข้าถึงระบบทั้งหมด |
| ผู้จัดการ | อนุมัติ PR จัดการงาน ดูงบประมาณ |
| ฝ่ายจัดซื้อ | จัดหาผู้ขาย สร้าง PO จัดการสินค้า |
| วิศวกร | สร้าง PR จัดการ BOM ดูคำสั่ง |
| ฝ่ายผลิต | จัดการใบสั่งผลิต เบิกวัตถุดิบ ติดตามผลผลิต |
| คลังสินค้า | รับของ จัดการสต็อก จัดส่งสินค้า |
| ฝ่ายบัญชี | แก้ไขคลังสินค้าและข้อมูลหลัก ดูคำสั่งซื้อได้อย่างเดียว |
| ผู้อ่าน | อ่านอย่างเดียวในทุกโมดูล |

ผู้ใช้หนึ่งคนมีได้หลายบทบาท สิทธิ์ที่ได้คือผลรวมของทุกบทบาท

## ปรับบทบาทและสร้างบทบาทเอง

หน้า **บทบาทและสิทธิ** ใช้แก้ไขชุดสิทธิ์ของแต่ละบทบาท บทบาทของระบบลบไม่ได้แต่ปรับสิทธิ์ได้ คุณสร้างบทบาทใหม่ด้วย **สร้างบทบาท** หรือกด **คัดลอก** จากบทบาทที่ใกล้เคียงแล้วค่อยแก้ สิทธิ์ที่มีความเสี่ยงสูงจะมีสัญลักษณ์กำกับและระบบจะถามยืนยันก่อนให้สิทธิ์ ส่วน **การเปลี่ยนแปลงล่าสุด** ด้านล่างแสดงประวัติการแก้ไข

## สิทธิ์เฉพาะบุคคล

เปิดผู้ใช้จากรายการ แล้วเลื่อนไปที่ **สิทธิ์เฉพาะบุคคล** สิทธิ์ที่มาจากบทบาทจะถูกล็อกไว้ ส่วนสิทธิ์อื่นกดให้เพิ่มเฉพาะคนนี้ได้ ระบบจะแสดง **สิทธิที่จะมีผลถ้าบันทึก** ให้ตรวจก่อนบันทึก

## ข้อมูลอ่อนไหวและเงินเดือน

ข้อมูลพนักงานบางส่วนแยกสิทธิ์ไว้ต่างหาก

- **ข้อมูลอ่อนไหว** เช่น เลขบัตรประชาชน เลขผู้เสียภาษี ประกันสังคม และบัญชีธนาคาร ดูได้เฉพาะผู้มีสิทธิ์ดูข้อมูลอ่อนไหว
- **เงินเดือน** เช่น อัตราค่าจ้าง ประวัติเงินเดือน และหน้าเงินเดือนทั้งหมด ดูได้เฉพาะผู้มีสิทธิ์ดูเงินเดือน

รายละเอียดอยู่ที่ [ข้อมูลพนักงาน](/th/docs/people/employees)

## ลบผู้ใช้หรือรีเซ็ตรหัสผ่าน

ในหน้ารายละเอียดผู้ใช้มี **รีเซ็ตรหัสผ่าน** (ระบบสร้างรหัสชั่วคราวให้ส่งต่อแก่ผู้ใช้) และ **ลบออกจากองค์กร** ในส่วน **โซนอันตราย** การลบจะปิดการเข้าใช้บริษัทนี้แต่ไม่ลบโปรไฟล์ และกด **เปิดใช้งานอีกครั้ง** ได้ภายหลัง

## เข้าสู่ระบบด้วยบัญชีองค์กร (SSO)

ทุกแพ็กเกจตั้งค่า SSO ได้ที่หน้า **ลงชื่อเข้าใช้ครั้งเดียว (SSO)** ในการตั้งค่า
